# AI: Dynamic Web Lab Generation for Core CSS Concepts

## Project Overview

This project demonstrates the use of sequential AI prompting to generate interactive web-based learning labs for core CSS concepts.

The project covers:

* CSS Box Model
* CSS `display` property
* CSS Flexbox
* CSS Grid
* Real-time CSS property manipulation using JavaScript

## Files

### `box_model_initial.html`

The initial AI-generated Box Model laboratory.

It demonstrates:

* Box 1 and Box 2 interaction
* Content, padding, margin, and border areas
* Width control
* Padding control
* Margin control
* Border width control
* Display property control
* Real-time JavaScript updates

### `box_model_refined.html`

The refined Box Model laboratory generated after a follow-up AI prompt.

It adds:

* Individual padding controls for top, right, bottom, and left
* Individual margin controls for top, right, bottom, and left
* Individual border-width controls for top, right, bottom, and left
* Corner-radius control
* Width control
* Display property control
* Real-time updates using JavaScript

### `flexbox_grid_playground.html`

An interactive playground for CSS Flexbox and Grid.

It provides controls for:

* `display`
* `flex-direction`
* `justify-content`
* `align-items`
* `grid-template-columns`

The layout updates in real time when the controls are changed.

## AI Workflow

The project was developed using sequential AI prompting.

1. Generate an initial CSS Box Model laboratory.
2. Refine the Box Model laboratory with side-specific controls.
3. Generate a separate Flexbox and Grid playground.
4. Test the generated interactive applications.
5. Save the generated applications as single-file HTML documents.

## Learning Objective

The goal of the project is to understand CSS layout concepts through interactive experimentation while learning how sequential AI prompting can be used to develop and refine web applications.
